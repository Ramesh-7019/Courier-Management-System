# Courier Management System

## Overview

A Full Stack Courier Management System developed using React, Spring Boot, and MySQL.

## Technologies Used

### Frontend
- React
- HTML
- CSS
- JavaScript
- Fetch API

### Backend
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

## Features

- Book Parcel
- View All Bookings
- Update Booking
- Delete Booking
- Auto Increment ID
- CRUD Operations

## Project Structure

```
CourierApplication   -> Spring Boot Backend
CourierFrontend      -> React Frontend
courier.sql          -> Database Script
```
